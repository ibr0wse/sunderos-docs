# User Guide

Welcome to the Sunderos user guide. These guides walk you through every feature of the app, from your first workout to advanced program planning.

---

## Guides

| # | Guide | Description |
|---|-------|-------------|
| 1 | [Getting Started](guide/getting-started.md) | Create your account, explore the app layout, and learn the basics of navigation |
| 2 | [Workouts](guide/workouts.md) | Start a workout, log your sets with weight/reps/RPE, use the rest timer and plate calculator, and finish with tags and notes |
| 3 | [Templates](guide/templates.md) | Browse built-in workout templates or create your own with custom set schemes, supersets, and RPE targets |
| 4 | [Programs](guide/programs.md) | Set up multi-week training programs with weekly or sequential scheduling and activate your plan |
| 5 | [Dashboard & Stats](guide/dashboard-and-stats.md) | View your training stats, volume-by-muscle charts, workout streaks, and frequency heatmap |
| 6 | [Body Weight](guide/body-weight.md) | Log your body weight over time and track trends with charts |
| 7 | [Workout History](guide/history.md) | Browse past workouts, view session details, and track exercise-level progress and PRs |
| 8 | [Settings](guide/settings.md) | Customize your preferences — units, rest timers, plate calculator, data export/import, and more |
| 9 | [API Keys & MCP Setup](guide/api-and-mcp.md) | Connect external tools like Claude to your fitness data using API keys and the MCP server |
| 10 | [Install as App (PWA)](guide/install-pwa.md) | Add the app to your home screen on iOS, Android, or desktop and use it offline |

---

**New here?** Start with the [Getting Started](guide/getting-started.md) guide, then head to [Workouts](guide/workouts.md) to log your first session.
